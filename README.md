## ✨ Features

✅ Fully Responsive layout (Desktop / Tablet / Mobile)  
✅ Modal-based **Search**, **Login**, and **Signup** forms  
✅ Dynamic **Add to Cart** system with item removal  
✅ **Dark / Light Mode** with local storage persistence  
✅ **Swiper.js** sliders for home, featured, new & testimonial sections  
✅ **ScrollReveal.js** animations for smooth section reveals  
✅ **Sticky Header** & **Scroll To Top** button  
✅ **Active Navigation Links** during scroll

## 🚀 Installation & Usage

1. **Clone this repository**
   ```bash
   git clone https://subodh-git77/granthWorld.git


2. **Navigate into the project**
   ````bash
   cd book-store

Open index.html

You can open directly in your browser

Or use a live server (recommended for development)

🌑 Dark/Light Mode

Toggle between Dark and Light themes using the theme button.
Your preference is saved in localStorage so it stays consistent on reload.

🛒 Cart System

🛍️ Add books to your cart dynamically and view them in a modal.
You can also remove items, and the cart count updates instantly.

🎬 Animations

Powered by ScrollReveal v4.0.9, all sections fade or slide into view as you scroll.
Animations can be customized by changing the reveal parameters in main.js.
